# Getting help

| You want to | Go to |
|---|---|
| Fix something that isn't working | [Troubleshooting](docs/troubleshooting.md), then a [bug report](https://github.com/Arkaya-Labs/Larch/issues/new?template=bug_report.yml) |
| Ask a question or share what you built | The [Arkaya Labs Discord](https://discord.gg/DxXXmEWbyy) |
| Ask for a model architecture | A [model request](https://github.com/Arkaya-Labs/Larch/issues/new?template=model_request.yml) |
| Suggest a feature | A [feature request](https://github.com/Arkaya-Labs/Larch/issues/new?template=feature_request.yml) |
| Report a security problem | The private route in [SECURITY.md](SECURITY.md). Not a public issue |

Larch is maintained by a small team. We read everything, but can't promise a reply time.
